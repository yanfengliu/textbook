# Study rounds

One dated note per agent round, newest by filename. Each says what the reader's record showed, what was concluded from it, and what changed in the book because of it.

These are written to the reader, not to a future agent. They are the honest history of what the system believed about someone's learning and what it did about it, which is the only way to notice later that it was wrong.

The format and the rules for a round are in [.claude/commands/study-round.md](../../../.claude/commands/study-round.md); the design behind it is [docs/design/adaptive.md](../../design/adaptive.md).
